Проект: Детекция преиктальных состояний ЭЭГ на основе графовых нейросетей с механизмом внимания

Задача: Бинарная классификация временных рядов (интериктальное vs преиктальное состояние) с дополнительной целью — сокращение размерности входных признаков (каналов) без потери качества. 
Формат: обучение с учителем.

Данные: CHB-MIT Scalp EEG Database. 
Предобработка включала фильтрацию (Баттерворт 1–45 Гц), удаление артефактов через FastICA (автоматическая детекция по спектральной мощности) и аугментацию скользящим окном (увеличение выборки с 112 до 784 графов). 
Признаки узлов: 7D-вектор (среднее, std + спектральная мощность в 5 диапазонах). 
Целевая переменная: бинарная метка состояния.

Реализовано два подхода для сравнения:
- GCN — агрегация соседей с фиксированными весами, игнорирование атрибутов рёбер.
- GATv2 — 2 слоя (7→64→2), multi-head attention (4 и 2 головы), dropout 0.2, ELU, глобальное усреднение, взвешенная Cross-Entropy Loss для баланса классов.

Обучение: Adam, L2-регуляризация, early stopping по F1-score на валидации, до 200 эпох.

Алгоритм отбора признаков (каналов): Извлечены attention weights из первого слоя GATv2, вычислена важность каждого канала как сумму весов внимания по всем рёбрам, 
запущено итеративное удаление наименее значимых каналов с переобучением и контролем F1-score.

Результаты:
- GATv2 превзошла GCN по Accuracy  и взвешенному F1-score
- Сокращение каналов: 17 → 5 (70.6%) при росте F1-score с 0.744 до 0.781.
- Анализ важности признаков показал доминирование Тета-ритма (вес 0.31), что согласуется с нейрофизиологией.
- Построены топографические карты, подтверждающие локализацию значимых каналов в центральной зоне коры.

Стек: Python, PyTorch, PyTorch Geometric, MNE, NumPy/SciPy (БПФ, фильтрация), Matplotlib.
